## 9. 表格
- 表头和数据行之间必须有分隔线  
- 分隔线至少需要三个连字符 ---  
- 端的竖线 | 是可选的，但建议保留以提高可读性  
- 不需要严格对齐，但对齐后更美观  
- ---: 设置内容和标题栏居右对齐  
- :--- 设置内容和标题栏居左对齐  
- :---: 设置内容和标题栏居中对齐  

| 左对齐 | 右对齐 | 居中对齐 |
| :----- | -----: | :------: |
| 单元格 | 单元格 |  单元格  |
| 单元格 | 单元格 |  单元格  |

| 功能                            | 描述                 |       状态       |
| ------------------------------- | -------------------- | :--------------: |
| **用户登录**                    | 支持邮箱和手机号登录 |     &#x2705;     |
| *密码重置*                      | 通过邮箱重置密码     | &#x26a0;&#xfe0f; |
| `API接口`                       | RESTful API 设计     |     &#x2705;     |
| [文档链接](https://example.com) | 查看详细文档         |    &#x1f4d6;     |
